# Sales Analysis Project
## Project Overview
This Project analyses a real-world Brazilian E-commerce dataset using python,pandas,Numpy and Power BI.
The objective was to clean,analyses and visualize sales data to generate meaningful business insights and recommandations.

## Tools USed
- Python
- Pandas
- Numpy
- power BI
- Jupyter Notebook

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

Dataset used:
- Olist_orders_dataset.csv
- Olist_order_items_dataset.csv
## Business Question Answered
- Total Revenue
- Total Freight Revenue
- Average Product Price
- Average Order Value
- To 10 Product By revenue
- Top 10 Sellers By Revenue
- Revenue trend By Month
- Order Status Distribution
- Correlation Between Product price and Freight cost
